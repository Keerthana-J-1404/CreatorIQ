# Screenshot capture checklist

No application screenshots are currently committed in this directory. Capture the running CreatorIQ application; do not use mockups or generated images as product screenshots.

- [ ] **Landing page:** Show the channel URL input and the available demo entry point.
- [ ] **Channel dashboard:** Show the channel overview, a visible data-source indicator, sample metrics, and recent-video chart.
- [ ] **AI strategy report:** Show a successfully generated report, its data-source notice, and evidence references. Do not include private provider credentials or personal account information.
- [ ] **Content Intelligence:** Show the recent-video comparison view and identify any static guidance as prototype content in the surrounding project documentation.
- [ ] **Memory Center:** Show the current prototype state without representing the data as persistent Hindsight Cloud memory.

Suggested filenames after capture:

```text
landing-page.png
channel-dashboard.png
ai-strategy-report.png
content-intelligence.png
memory-center.png
```

Add image files to this directory and link to them from the root `README.md` using relative paths. Before committing, inspect screenshots for API keys, browser profile details, private channel data, and other sensitive information.
